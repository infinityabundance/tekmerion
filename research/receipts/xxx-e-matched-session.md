## 1. Definition and method

Matched session = **one HOL session** in which

1. `needs "arm/proofs/base.ml"` and the task setup (`define_assert_from_elf`,
   `ARM_MK_EXEC_RULE`, `let p_25519 = new_definition ...`) are evaluated — these are
   **before** `stamp_before` in the strict run, so they are outside both counters;
2. `let ix89_lib_before = inference_count ()`, then the **support library** (the 327
   inlined `let` phrases from `dimacs.ml`, `cnf.ml`, `ldrup.ml`, `csat_lib.ml`,
   `bridge.ml`, in the emitter's exact order and text) is built and kernel-checked;
   **L7 = inference_count () − ix89_lib_before**;
3. the counter is reset by taking a new baseline (`let ix89_task_before = inference_count ()`);
   the **task-only** `time prove (<query>, <tactic>)` is then evaluated;
   **matched = inference_count () − ix89_task_before**;
4. the theorem is produced, and the same-session statement/hypothesis/axiom check
   (`stmt_check.sh inject`) runs and must print `STATEMENT_OK … aconv=1 hyps=0 axioms=3`.

The emitter was not changed and no answer text was edited. The split is taken from the
strict generated proof at the boundary `inline_answer::render` produces
(`\nin\n(fun g ->\n  try\n`): everything before it is the library, the function after it
is the task tactic.

## 4. Dependency control — the task builds only because the library is loaded

A control session with the header + the task-only `prove` call and **no** library, built the
same way (`build-proof.sh`, capped at 12 G), fails at compile time:

```
Error: Unbound value csat_mark_reader
CONTROL_BUILD_RC=2
cap.sh: group=2946800 rc=2 sampled_group_peak_rss_kb=250168 max_process_vmhwm_kb=244076
```

`csat_mark_reader` (and `BRIDGE_ADD_REF_ALG_TAC`, etc.) are defined only in the phrases
(`phrases.ml`), never in the header or `base.ml`. So the theorem cannot be produced without
the preloaded library.

**No library phrase is re-executed after the reset:** `arm_<op>_p25519.task.ml` is exactly
`let TH = time prove (<query>, <tactic>);;` — 0 top-level `;;` separators, no library text
(and the split script aborts if the DIMACS banner leaks into the task file).

## 6. What is measured, what is not

- **Measured in-session:** `L7 = 1,496,597` (once, identically in three sessions); matched
  totals `2,591,777 / 3,472,959 / 1,351,423`; strict totals reproduced as
  `L7 + matched` (`4,088,374 / 4,969,556 / 2,848,020`); `STATEMENT_OK` and the axiom set.
- **No number here is `strict − L7`.** The matched total is the direct counter reading after
  the reset; the equality `strict − L7 = matched` is a *cross-check*, not the source of the
  figure.
- **Not measured:** timing medians, and any other task family. Each task was run once; the
  three agree on `L7` and reproduce the strict totals exactly, which is the reproducibility
  evidence available at this budget.
- The human baselines (1,848,494 / 1,283,174 / 721,473) are carried from IX.99 and are not
  re-measured here.
